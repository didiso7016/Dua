# 首頁與找建案

## 使用流程

首頁保留角色與縣市／行政區搜尋。最新刊登最多6案，桌機三欄、手機單排手動輪播（手指滑動、左右箭頭、目前筆數）。不足6案即顯示實際數量，不重複資料。

「幫我挑個家」依序詢問地區、總價預算、房型、住宅類型，每一步可不限；房型支援8種分類複選。結果顯示在首頁，可進入找建案頁繼續調整，透過URL保留條件，不需登入或留電話。

找建案頁集中篩選地區、預算、房型及住宅類型，生活需求收在更多篩選。支援清除條件、目前條件摘要、空結果，以及WebMCP filter_projects讀取與篩選。

## 後台與價格

- 各建案「基本資料」新增最低／最高總價（萬元）、車位計價、價格確認日期及找房用房型分類。未選房型分類時依格局與原房型文字判讀。
- 價格兩端皆空白＝價格待確認；不會混入符合預算的結果，另以可展開區塊呈現。
- 價格區間完全位於預算內且含車位，才標示刊登總價符合預算。部分重疊、起價未有上限、或車位另計／未知，皆提示部分可能符合並請確認實際總價。
- 不預填本案未提供的總價，也不假設車位含在內。
- 最新排序採publishedAt。首次刊登時由伺服器設定；後續修改、下架再刊登不重設。舊案無歷史首次時間時採當時既有updated_at作為起點，不回填虛構日期。
- 公開找房元件只傳遞所需的公開欄位，不序列化銷售窗口、通知Email或試算表接收網址。

## 首頁與瀏覽統計

後台側欄「首頁與瀏覽統計」可：

1. 管理1–12組預算級距，新增、修改、排序、移除；不限固定保留。
2. 管理最多10個推薦橫幅：圖片、標題、說明、連結、顯示、排序及起迄日期。日期以Asia/Taipei判定，含開始／結束當日。未填完整或不在日期範圍時隱藏。
3. 付費版位選廣告／贊助，前台清楚標示，不影響熱門排序。圖片使用原圖片上傳管道，未公開橫幅的R2照片只供管理者使用。
4. 查看近30天各案有效瀏覽次數，預設不顯示熱門區塊。開啟且至少3個已刊登案有瀏覽、合計至少10次後，首頁才顯示最多3個熱門案。

瀏覽計數在建案介紹頁停留2秒後送出；背景頁面不計時。管理者、未儲存預覽、本機預覽環境、常見機器User-Agent及啟用不追蹤的訪客不計入。伺服器檢查同源請求；使用匿名HttpOnly、SameSite=Lax、Secure cookie，依本案／臺灣日期雜湊去重，不保存IP或原始cookie。每個瀏覽器每案每日最多一次，這是有效瀏覽近似值，不是精確人數，也不能完全阻擋偽裝流量。

統計使用既有settings表的view-hit與view-count命名空間，以批次交易去重並原子增加每日計數；自功能上線起累積。原始去重及彙總保留35天，收到新計數時清理到期資料。後台只提供彙總，不提供個別瀏覽識別碼。首頁、預算級距與橫幅存於獨立home設定，不會被公司資訊儲存覆蓋。不需改動資料表或另外設定排程。

## 2026-11-02 探索首頁與共用找房流程
- 首頁改為米白／炭黑／湖藍、粉彩面板的雙欄探索頁；角色、大小交錯標題與原建案照片並用。
- 移除首頁獨立地區搜尋及完成後的重複結果；四題問答可略過、返回或提早查看，直接導向 `/projects` 共用 URL 條件。
- 最新、熱門、精選共用一個探索面板；有符合既有排程的編輯精選才顯示頂部消息，無內容不造假。沿用現有後台首頁／瀏覽統計設定。
- 找建案頁預設只顯示條件摘要與結果；修改條件展開原有篩選，不重填。可逐項移除或清空；零結果提供放寬條件。
- 本機 localStorage `dua-search-v1` 只儲存找房條件；第一次只瀏覽首頁不寫入。再次進入可接續、修改或重新開始。明確 `/projects?all=1` 代表看全部，避免被舊條件覆蓋。網址內條件優先於本機記錄。
- 列表點入個案時，以 sessionStorage `dua-list-return` 暫存目前 URL、scrollY 與時間；一小時內回到同網址還原位置。Header 的找建案連結沿用儲存條件，非敏感資料且不跨裝置同步。
- 原建案詳細頁內容、後台驗證、個資名單與 Footer 設計維持；只在共用 Header 的找建案連結加入條件延續。
- 動畫僅題目內容淡入；遵循 reduced-motion。探索頁與結果頁樣式有獨立範圍。
