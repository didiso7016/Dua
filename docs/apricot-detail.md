# 杏桃版建案介紹頁

- 基本資料、格局、機能與位置沿用原資料；首頁配色不受影響。
- 建案優勢：後台「建案優勢」新增標題與選填說明，可排序、移除，最多20項。電腦每排5項；1100px以下單排輪播，中央放大，左右縮小，5秒自動切換。手動切換後暫停，不顯示播放／暫停文字與圖示；滑鼠停留、鍵盤焦點、區塊離開畫面、背景分頁皆暫停。減少動態模式不自動播放。
- 本案5個標題與Facebook連結於舊資料缺少新欄位時補入；空字串與空陣列保留，可由後台清除。其他建案預設空白。不改寫既有建案其他欄位。
- 位置：填入HTTPS Facebook網址，顯示在接待會館資訊下方，未填不顯示。
- 版面設定：段落名稱同步導覽與標題。格局或機能可切換「只使用新增段落」，再於「新增段落」選擇對應章節，新增空拍滿版圖、輪播或文字。切換不刪除原格局、機能資料，改回原有內容即可恢復。
- 所有行政區文字顯示，僅本案行政區變色。圖資來源及版本見district-map.md。
- 進場使用一次性淡入與微移，照片切換淡入。首圖多張時6秒自動輪播，不顯示播放／暫停控制，手動切換或放大後暫停；減少動態模式不自動播放。單張不顯示播放控制。

## 首屏、格局與影片更新

- 桌機保留74px精簡Header，Header＋案名＋完整首圖合計一個螢幕；首圖contain不裁切。手機維持照片原比例。
- 標題加粗、內文17–18px與1.65倍行距，輔助文字同步調整。
- 「照片與格局」可選1房、1+1房、2房、2+1房、3房、3+1房、4房、4+1房，並填寫每戶說明。分類空白時依既有房型規格判讀，舊資料不需重建。前台僅顯示現有分類，先選房型再選戶別。
- 「新增段落」新增「影片＋說明」，支援YouTube watch、youtu.be、shorts、embed網址。未點選不載入外部影片；點選後載入YouTube隱私加強版播放器。未填網址的影片段落隱藏。
- 位置區：桌機左表單、右地圖與接待資訊；900px以下先地圖與按鈕，後表單。接待中心導航優先使用獨立網址；未填且接待中心異址時依接待地址導航；同址沿用基地網址。電話為本案專用電話，不會使用公司電話替代。
- 後台「位置」設定本案電話與接待中心導航；「平台資訊」設定公司FB、IG。未填連結不顯示對應按鈕。舊公司資料讀取時合併預設社群網址，使用者清空後儲存則保持清空。
- Footer使用可可棕、公司圖示資訊與社群連結。右下返回頂部在捲動400px後顯示，避開手機預約列及頁尾社群圖示。
