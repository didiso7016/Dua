# 自訂基本資料欄位

後台「建案管理 → 編輯建案 → 基本資料」下方新增「詳細頁基本資料欄位」。

- 可新增欄位名稱及內容、上移／下移、隱藏／移除，以及選擇占滿一整排。
- 每案最多40個欄位，名稱80字、內容2000字。名稱或內容空白即不顯示，不產生「待確認」或空白列。
- 原有的建商、房型、全案坪數、建案類型及銷售狀態，內容仍從上方基本資料連動。可改顯示名稱及排序；改名、隱藏或移除表格欄位不會刪除首頁及搜尋資料。
- 移除原有欄位後，可用「加入原有欄位」加回；每種原有欄位只能加入一次。
- 自訂欄位如投資興建、建築代銷、建照號碼完全依各案填寫，不推測或預填資料。
- 尚無facts設定的舊資料自動沿用原有5欄；明確儲存空陣列代表不顯示任何表格欄位。所有資料仍存於各建案既有JSON，無需變更資料表。
- 前台以伺服器輸出的dl/dt/dd呈現，欄位名稱與值為一般文字；與原基本資料表格共用字級及細線，整排欄位不受「第一欄」位置限制。
- 未儲存預覽及草稿／刊登共用同一份編輯資料，須按儲存才更新前台。
