# 功能與完成狀態

## 已實作
前台首頁互動問答、共用搜尋條件、價格未知分組、回訪需求與列表位置保存；最新刊登、實際統計熱門、設定好的精選／廣告。建案介紹包含首圖輪播、圖片放大、行政區地圖、自訂基本資料、優勢輪播、房型及戶別、周邊機能、位置、社群與預約。後台管理建案、照片、價格、房型、段落模板與排序、公司資訊、首頁設定及預約名單。管理員驗證保護管理 API 與草稿。

2026-11：新增隱私權政策頁 /privacy（預約與洽詢表單只保留一行「我已閱讀並同意隱私權政策」，同意版本 privacy-2026-11）；聯絡我們頁 /contact 與全站洽詢彈窗（一般洽詢／合作洽詢，右下「洽詢」按鈕）；洽詢存入 D1 inquiries 並寫入公司總表「洽詢名單」分頁；後台「洽詢名單」。/about 併入 /partner#about。

## 依資料顯示
沒有正式消息不顯示消息帶；只有一種探索內容不顯示重複的切換按鈕。熱門需啟用且符合資料門檻；廣告依可見與刊登日期。未提供圖片／FAQ 等資料的區塊不應假造內容。華邑範例全案 22–27 坪，A3 單戶坪數待確認，未提供總價。

## 外部設定尚待完成
- Google Sheets：需 Google 擁有者完成 Apps Script 授權、部署及 URL／token 設定。程式及設定介面已備妥，不代表目前已連線。失敗名單可手動重試，沒有排程重試。洽詢名單需重新貼上新版接收程式並發布新版本（docs/sheets-inquiries.md），正式 D1 需套用 drizzle/0001_inquiries.sql。
- 忘記密碼：需 Resend 金鑰、驗證寄件地址及站點網址，未設定不會寄信。
- 搜尋／GEO：已包含可讀取內容、標題摘要、結構化資料與網站搜尋相關路由；不保證索引或 AI 引用。
