# 建案自由段落

後台 → 建案管理 → 編輯建案 → 新增段落。

1. 選擇滿版大圖、左圖右文、右圖左文、照片輪播＋說明或純文字。
2. 選擇插在認識建案、空間格局、周邊生活或位置與預約之後。
3. 填寫選填的標題／說明、上傳圖片；滿版大圖限 1 張，其他圖片版型每段最多 20 張，每案最多 30 段。
4. 可在同一位置上移、下移，也可更改位置、隱藏或移除段落。上方快速導覽保留主要分類。
5. 「預覽目前編輯」顯示尚未儲存的內容，停用預約表單；返回編輯會保留內容及目前分頁。
6. 「更新刊登內容」後訪客才會看到變更；「儲存草稿／下架」則會將整個建案下架。

照片完整顯示、不裁切。滿版大圖依原比例延伸到頁面兩側，沒有標題、說明、圖片說明時僅呈現照片；照片仍可點擊放大。圖片版型的標題文字未填可略過，但照片未上傳的滿版／輪播段落不會顯示。隱藏段落不保留空白。

資料保存在 projects.data JSON 的 contentBlocks 欄位，不需要新增資料表。舊案讀取時預設空陣列，既有內容不會被覆寫。新增段落圖片需在已刊登、可見且所屬主區塊可見時才開放訪客讀取；管理者可看草稿圖片。

桌機主要區塊縮減上下間距，格局與一般照片依視窗高度等比縮放。長文字、多個機能區塊及滿版大圖維持自然高度，不鎖死內容、不截字。手機採單欄自然閱讀。
