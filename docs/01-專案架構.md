# 專案架構

## 技術
React 19、TypeScript、Vinext／Vite（Next App Router 相容）、Cloudflare Workers、D1 SQLite、R2；pnpm 鎖定依賴。

- worker/index.ts：Worker 進入點，把請求交給 vinext。
- wrangler.jsonc：Worker 名稱、D1（DB）與 R2（BUCKET）binding；本機與正式部署共用。
- styles/：新設計系統（tokens、base、元件、Header／Footer）；app/globals.css 只剩尚未改版頁面的舊樣式。
- vendor/：shadcn 的 Tailwind 樣式，由 globals.css 引用，必須保留。
- dist/、.vinext/、.wrangler/ 是自動產生的輸出或本機狀態，不提交。

2026-11 起已移除 ChatGPT Sites 專用的設定（.openai/、build/、scripts 內的 Sites 安裝與 connector preview），正式站改部署到公司自己的 Cloudflare。

## API
- /api/admin/projects：管理建案，需登入。
- /api/admin/settings：公司設定，需登入。
- /api/admin/home：首頁設定，需登入。
- /api/admin/upload：圖片上傳，需登入。
- /api/admin/bookings：預約名單與管理，需登入。
- /api/admin/sheets：Sheet 設定與同步操作，需登入。
- /api/admin/analytics：彙總瀏覽統計，需登入。
- /api/auth/[action]：登入、登出及密碼相關動作。
- /api/bookings：公開預約送出；依表單驗證保存資料。
- /api/inquiries：公開洽詢送出（一般／合作）；保存後寫入公司總表「洽詢名單」分頁。
- /api/admin/inquiries：洽詢名單（?type=general|partner），需登入。
- /api/views：公開頁瀏覽計數，有來源、機器人與重複過濾。
- /api/media/[key]：圖片讀取與公開／草稿權限檢查。
